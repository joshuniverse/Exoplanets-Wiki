# Precision radial-velocity spectrographs

Precision RV work is instrument-driven. You’ll see the same names across many papers.

### Commonly cited spectrographs

* **HARPS / HARPS-N**
* **ESPRESSO**
* **CARMENES**
* **NEID**
* **HIRES / Keck** (legacy and upgrades)

### What to watch in RV papers

* Instrument zero-point offsets.
* Sampling cadence and aliases.
* Stellar activity modeling.

{% hint style="info" %}
When someone says “mass confirmed”, ask: which instrument and what cadence?
{% endhint %}
