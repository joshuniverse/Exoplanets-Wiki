# CHEOPS

CHEOPS is built for **high-precision** transit photometry. It’s often used to refine:

* Transit depth and ephemerides.
* Small planets around bright stars.

### Typical use cases

* Tightening radii for RV planets.
* Searching for additional transits.
* Refining timing for JWST planning.

{% hint style="info" %}
CHEOPS is follow-up, not a wide-field discovery survey.
{% endhint %}
