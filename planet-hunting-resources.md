### Quick links

#### Core catalogs

* [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/) — official-ish “source of truth” for many parameters.
* [Exoplanets.org](https://exoplanets.org/) — Exoplanet Data Explorer.
* [The Extrasolar Planets Encyclopaedia (exoplanet.eu)](https://exoplanet.eu/) — long-running community catalog.

#### Citizen science

* [Planet Hunters (Zooniverse)](https://www.planethunters.org/) — transit hunting with the public.

#### Mission discovery pages

* [Kepler discoveries](https://kepler.nasa.gov/Mission/discoveries/) — classic transit mission results.
* [TESS mission](https://tess.mit.edu/) — current all-sky transit survey.
* [NASA Exoplanet Exploration — program overview](https://exoplanets.nasa.gov/)
* [JPL ExEP program overview](https://exoplanets.jpl.nasa.gov/programoverview/)

#### More mission + instrument context

* [ESA CHEOPS](https://www.esa.int/Science_Exploration/Space_Science/Cheops) — precision follow-up photometry.
* [ESA PLATO](https://www.esa.int/Science_Exploration/Space_Science/PLATO) — upcoming transits + asteroseismology.
* [ESA ARIEL](https://www.esa.int/Science_Exploration/Space_Science/Ariel) — future atmospheric survey.
* [JWST](https://www.stsci.edu/jwst) — transit / eclipse spectroscopy for atmospheres.

#### Modeling + analysis tools (common in “planet hunting” workflows)

* [exoplanet (Python)](https://docs.exoplanet.codes/en/stable/) — probabilistic modeling with PyMC.
* [batman (Python)](https://lweb.cfa.harvard.edu/~lkreidberg/batman/) — transit light-curve model.
* [radvel (Python)](https://radvel.readthedocs.io/en/latest/) — radial-velocity orbit fitting.

#### Papers and literature

* [arXiv: astro-ph.EP (Earth and Planetary Astrophysics)](https://arxiv.org/list/astro-ph.EP/recent)
* [NASA ADS](https://ui.adsabs.harvard.edu/) — search and filter by keyword, mission, target.

#### Follow-up and target vetting

* [ExoFOP-TESS](https://exofop.ipac.caltech.edu/tess/) — community follow-up for TESS candidates.

### What to use, depending on the question

* **“Is this object confirmed?”** Start with NASA Exoplanet Archive. Cross-check exoplanet.eu.
* **“Where did this parameter come from?”** Use ADS to find the discovery / characterization paper.
* **“Is there follow-up photometry / RV work?”** Check ExoFOP-TESS for recent activity.
