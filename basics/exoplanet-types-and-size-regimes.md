# Exoplanet types and size regimes

These labels are fuzzy. Different papers use different cut lines.

### By size (rough)

* **Earth-size**: \~1 $$R_\oplus$$.
* **Super-Earth**: bigger than Earth, smaller than Neptune.
* **Sub-Neptune / mini-Neptune**: typically \~2–4 $$R_\oplus$$.
* **Neptune-size**: \~4 $$R_\oplus$$.
* **Gas giant**: Jupiter-size and above.

### By temperature / irradiation

* **Hot**: close-in, high irradiation.
* **Warm**: intermediate.
* **Cold**: outer orbits, low irradiation.

### By composition (inferred)

* **Rocky**: high density, small radius.
* **Volatile-rich**: lower density, often with H/He.
* **Ice giant-like**: intermediate composition.

{% hint style="info" %}
If you want to be precise, quote $$R_p$$ and $$S$$. The label can follow.
{% endhint %}
