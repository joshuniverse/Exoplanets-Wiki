# Naming & designations

Most names encode the **survey** and the **host star**.

### Common patterns

* **Star name + letter**: `51 Peg b`, `TRAPPIST-1 e`.
* **Catalog IDs**: `HD 209458 b`, `HIP 41378 f`.
* **Survey candidates**: `TOI-700.01` (candidate), later becomes `TOI-700 b` (confirmed/validated).

### Letters are by discovery order

* `b` is the **first planet** discovered around that star.
* It is not the innermost planet.

### Binary stars and circumbinary systems

Naming gets messy when there are multiple stars.

You’ll see forms like:

* `Kepler-16 (AB) b` for circumbinary planets.

### What to do when names disagree

* Use the **NASA Exoplanet Archive** name as the default.
* Put common aliases in parentheses.
* Link the discovery paper.

{% hint style="info" %}
If you’re building a dataset, join on a stable identifier (e.g., Gaia DR3 ID).
{% endhint %}
