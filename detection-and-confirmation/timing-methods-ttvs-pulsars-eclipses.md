# Timing methods (TTVs, pulsars, eclipses)

If a system is a good clock, planets mess with the schedule.

### Transit timing variations (TTVs)

In multi-planet systems, planets tug on each other. Transit times shift.

* Great for compact resonant systems.
* Can constrain masses and eccentricities.

### Pulsar timing

Pulsars are extreme clocks. Planets produce periodic timing residuals.

* First confirmed exoplanets were around a pulsar.
* Rare, but ultra-precise.

### Eclipse timing

Binary stars have eclipses. Third bodies can shift eclipse times.

{% hint style="warning" %}
Timing claims can be fragile. Activity cycles and systematics can fake signals.
{% endhint %}
