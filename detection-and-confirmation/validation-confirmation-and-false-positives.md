# Validation, confirmation, and false positives

### The basic ladder

* **Detection**: you see a signal.
* **Vetting**: you rule out obvious non-planet causes.
* **Validation**: you show the planet scenario dominates.
* **Confirmation**: you measure a dynamical effect (mass, interactions).

### Statistical validation

Common ingredients:

* Population priors (how common planets vs binaries are).
* Imaging constraints on background stars.
* Light curve shape tests.

### Common false positives

* Grazing eclipsing binaries.
* Background blends.
* Dilution from unresolved companions.
* Stellar activity (especially in RV).

### What “confirmed” means in catalogs

Definitions differ.

* Some catalogs use **validated** as confirmed.
* Some reserve confirmed for **mass-confirmed**.
