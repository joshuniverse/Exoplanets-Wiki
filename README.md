### What you’ll find here

* **Definitions** and the common vocabulary used in papers and catalogs.
* **Detection method primers** with the usual caveats and failure modes.
* **Mission and telescope context** so you know where a dataset came from.
* **Notable targets** you can use as benchmarks.
* **Data entry points** (archives + tools) for light curves and tables.

### Contributing

* Add links that are **stable**, **primary-source**, and **actively maintained**.
* Prefer official archives (NASA/ESA/STScI) and peer-reviewed references.
* If a link is paywalled, also add the arXiv or ADS record when available.
