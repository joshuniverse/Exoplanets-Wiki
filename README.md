# Welcome to the Exoplanets Wiki

This wiki is a starting point for **finding**, **verifying**, and **discussing** exoplanets.

Use it like a launchpad. Jump to the catalog. Pull the data. Read the paper.

### Start here

* [Planet-hunting resources](planet-hunting-resources.md)
* [Catalogs & data](catalogs-and-data.md)
* [Community (r/Exoplanets)](community-r-exoplanets.md)

### What you’ll find here

* **Fast links** to the main catalogs and mission pages.
* **Data entry points** (archives + tools) for light curves and tables.
* **Community feeds** to track discoveries, research, and visualizations.

### Contributing

* Add links that are **stable**, **primary-source**, and **actively maintained**.
* Prefer official archives (NASA/ESA/STScI) and peer-reviewed references.
* If a link is paywalled, also add the arXiv or ADS record when available.
